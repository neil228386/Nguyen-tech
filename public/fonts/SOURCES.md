# Be Vietnam Pro font

Font files downloaded from the Fontsource npm package through jsDelivr:
`https://cdn.jsdelivr.net/npm/@fontsource/be-vietnam-pro@latest/files/`.

Included subsets: Latin, Latin Extended and Vietnamese. Included weights: 400, 500, 600 and 700, normal style. Serving these files locally avoids a runtime request to Google Fonts.

The bundled `LICENSE` contains the source package SIL Open Font License 1.1 notice.

Fetched package version: `5.3.0`.
