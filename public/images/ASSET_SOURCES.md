# Demo image sources

All images are local so the storefront does not depend on third-party image CDNs at runtime. The image set is for the demonstration catalogue: several photographs depict older or representative devices rather than the exact SKU in the listing. The product detail page displays an image disclaimer.

The repository licenses below describe the source repositories; a repository license alone does not establish ownership of manufacturer product photographs or trademarks. Before publishing a commercial store, replace representative images with exact SKU photographs supplied by the shop or an authorized distributor, with permission to use them.

Files preserve the original downloaded bytes. Some filenames end in `.jpg` but contain PNG or WebP data, supported by current browsers.
